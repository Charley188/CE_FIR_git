# FIR / FFT 设计方法对齐验证

日期：2026-09-24。MATLAB R2025b。此记录仅验证MATLAB算法，硬件验证边界仍见VALIDATION.md。

测试源：`validation/test_fir_vna_algorithm.m`。运行时传入FFT参考工程目录和仓库之外的临时输出目录；不要将临时测量、MAT/CSV/图像和日志上库。

## 结果

| 测试 | 结果 |
|---|---|
| 调用实际未修改的FFT ce_vna，与FIR设计器对照 | 归一化频率、257tap及参数相同时，浮点tap最大差 1.168e-14 |
| 平坦−20dB合成通道 | 目标保留0.1幅度，量化后纹波0.04111dB，电平偏差−0.000617dB |
| 300tap平滑幅相畸变合成通道 | 幅度纹波4.43692→0.042595dB；最大残余相位0.10658° |
| 强凹陷、增益受限通道 | 4次求解后增益界4.94642dB≤6dB；仍有45.7583dB纹波，不能视为成功校准 |
| 不可实现的总目标延迟 | 指标明确显示巨大幅相残差，没有声称校准成功 |
| 错误输入与不可达增益限制 | 重复频率、点数不足、无法满足的限制均被拒绝 |
| 导出 | H=1 MEM正确；MAT/CSV输入产生相同量化系数；300行MEM与量化tap逐项一致 |

FIR和FFT使用不同的硬件系数量化位置。因此浮点设计等价测试选择两种量化均不会触发重试的通道；并未声称两种硬件的量化输出完全相同。

本次仅修改FIR MATLAB及文档/测试源。FFT入口和设计器、PS系数文件通过修改前后SHA-256检查保持一致。

原来的数字主链路0 LSB记录证明RTL与定点运算一致，并不证明此次实测通道已被修正。本次没有用户实测bypass数据，不能保证板上改善。
