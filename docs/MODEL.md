# 定点链路与验证边界

主 TB 和 ADDA 共用 rtl/adda_first_path_chain.v，包括三个时钟域的复位同步、ADC I/Q 成对握手、跨时钟 FIFO、复数 FIR、插值和 DAC gearbox。

数学模型：

1. 8 lane 输入按 lane0→lane7 展开，抽取器选择全局索引 0、12、24……；没有额外抗混叠滤波。
2. 四个实数 FIR 实现 I*Cr−Q*Ci、I*Ci+Q*Cr。COE 是 signed18 整数，表示 Q2.16。
3. FIR 全精度结果扩展到 41 位，复数加减后算术右移 16 位（向负无穷取整），饱和到 signed16。
4. 3×2×2 每一级使用当前 COE，逐级右移 16 位、饱和，半带直通相位使用 RTL 对应的固定延迟。
5. 每个 DAC beat 的 lane0 位于低 32 位，I 在低 16 位、Q 在高 16 位。

MATLAB 使用整数输入及双精度卷积，累加值限制在 2^40 内，因此整数乘加在双精度 53 位有效精度内可精确表示；插值沿用 int64 位精确模型。
模式一添加 FIR 尾部和插值冲刷零，模式二处理输入文件中的全部样本，不额外追加或移除未知样本。

TB 的 ADC/DAC 时钟均约 300 MHz，但有相位差；算法时钟 200 MHz；DAC 施加确定性背压。比较按有效握手后的样本次序，不比较模拟时钟延迟。

本主 TB 验证数字生产链路第一路，不建模 RFDC 模拟性能、射频 NCO、板上时序或第二路 RFDC 直通支路。板级 sys_top 保留原设计。
系数宽度/RTL 缩放改动属于新的定点配置，不能只改 MATLAB 数字就视为位宽优化验证完成。
